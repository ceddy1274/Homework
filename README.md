# Homework
This is a GitHub repository of many of the programming assignments I have done while at the University of Arkansas. It is split up into folders by class and then another layer of subfolders for each homework assignment. Some of the projects were multiple homework assignments all split into different parts of one larger project.

## 📂 Project Structure
- **Data Mining** - Data analysis and machine learning projects
- **Operating Systems** - System programming and concurrency projects
- **Programming Foundations I & II** - Fundamental programming concepts
- **Programming Paradigms** - Multi-language programming projects

## 🚀 Quick Start for Java Homework
The Java Homework is a popular project - here's how to get it running:

### Prerequisites
- Java JDK 8+ installed and in your PATH
- GUI-capable system (uses Java Swing)

### Download & Run
```bash
# Clone the repository
git clone https://github.com/ceddy1274/Homework.git
cd "Homework/Programming Paradigms/Java Homework"

# Run on Linux/macOS
chmod +x run.bash && ./run.bash

# Or run on Windows
run.bat
```

For detailed instructions, see the [Java Homework README](Programming%20Paradigms/Java%20Homework/README.md).
